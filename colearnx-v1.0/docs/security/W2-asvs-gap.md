## 未评估章节及理由

- **V1（架构）**：文档类要求，本次以威胁模型文档一并覆盖。
- **V6（密码学）**：已抽查关键点（argon2id、HMAC-SHA256、`randomBytes`、`timingSafeEqual`），
  均为正确选型，无自研算法，故不逐条展开。
- **V10（恶意代码）**、**V11（业务逻辑）**：并入 W7 风控与 W9 供应链专项。
- **V6.2 加密存储**：当前无静态加密需求（口令为哈希、支付凭据不落库）。
